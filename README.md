# Petology Web

[![Stack: Full-Stack](https://img.shields.io/badge/Stack-Node.js%20%7C%20React-blue.svg)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

> A modern full-stack web application designed for veterinary clinics and pet owners to streamline appointments, manage medical history records, and access pet care services.

---

## ✨ Features

- **Pet Owner & Vet Portals**: Dual-role user access for booking appointments and reviewing medical logs.
- **Appointment Scheduling**: Interactive calendar for selecting veterinary service slots.
- **Medical Records Management**: Organized dashboard for tracking vaccination records, prescriptions, and health history.
- **Responsive UI**: Optimized for mobile and desktop screens.

---

## 🛠 Tech Stack

- **Frontend**: React, Tailwind CSS, Axios
- **Backend**: Node.js, Express.js
- **Database**: MongoDB / PostgreSQL
- **Authentication**: JWT-based session management

---

## 🚀 Local Setup Guide

```bash
# Clone repository
git clone https://github.com/ahmedfawzyjr/petology-web.git
cd petology-web

# Install dependencies
npm install

# Set up environment variables (.env)
cp .env.example .env

# Run development server
npm run dev
```
